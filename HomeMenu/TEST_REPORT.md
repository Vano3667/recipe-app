# Отчёт о тестировании

## Статус: тесты написаны, но ещё не запускались

Проект готовился в изолированной среде без JDK, Android SDK, Gradle, эмулятора и доступа в интернет (подробно в ENVIRONMENT.md). Поэтому:

- **APK ещё не собран.** Его соберёт GitHub Actions (задача `build`, артефакт `home-menu-debug-apk`).
- **Тесты не запускались.** Ниже результаты помечены как «ожидается». Настоящие результаты появятся в артефакте `reports` и в логах задач `build` / `instrumented`.
- Вместо компиляции сделана статическая проверка: все импорты `com.example.homemenu.*` (44 файла Kotlin) ссылаются на существующие объявления, а сигнатуры, которые используют навигация и тесты, сверены с кодом вручную.

После первого прогона CI замените статусы на фактические.

## Пограничные случаи и где они обработаны

| Случай | Поведение | Покрытие |
|---|---|---|
| Пустые списки | иллюстрированные пустые состояния с действием | Robolectric, вручную |
| Удаление рецепта из меню | предупреждение «запланирован N раз», записи меню удаляются; блюда без рецепта пропускаются в сводке и покупках | MenuSummaryTest |
| Порции ≤ 0 | валидация формы; степперы min = 1; генератор ≥ 1; scale бросает исключение | юнит |
| Длинный текст | maxLines/ellipsis в карточках, перенос в рецепте | валидатор, вручную |
| Фото > 5 МБ | даунсэмплинг до 1080 px + JPEG 85 % | PhotoSampleSizeTest |
| Бэкап без `photos/` | импорт рецептов без фото | вручную |
| Несовместимая версия JSON | понятное сообщение, база не меняется | BackupJsonTest |
| Разрешение камеры | запрос по требованию; при отказе — сообщение, галерея доступна | вручную |
| Поворот экрана | состояние в ViewModel / rememberSaveable | вручную |

## Известные риски первого запуска CI

- `lint abortOnError = true`: первый прогон может остановиться на предупреждениях. Пришлите лог — исправлю.
- Шрифты скачиваются с github.com/google/fonts; без них ресурсы `R.font.*` не соберутся.
- Инструментальный тест фото использует `file://` URI; на некоторых образах эмулятора может понадобиться `content://`.
