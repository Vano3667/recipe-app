## Пограничные случаи и где они обработаны

| Случай | Поведение | Покрытие |
|---|---|---|
| Пустые списки | иллюстрированные пустые состояния с действием | Robolectric, вручную |
| Удаление рецепта из меню | предупреждение «запланирован N раз», записи меню удаляются; блюда без рецепта пропускаются в сводке и покупках | MenuSummaryTest |
| Порции ≤ 0 | валидация формы; степперы min = 1; генератор ≥ 1; scale бросает исключение | юнит |
| Длинный текст | maxLines/ellipsis в карточках, перенос в рецепте | валидатор, вручную |
| Фото > 5 МБ | даунсэмплинг до 1080 px + JPEG 85 % | PhotoSampleSizeTest |
| Бэкап без `photos/` | импорт рецептов без фото | вручную |
| Несовместимая версия JSON | понятное сообщение, база не меняется | BackupJsonTest |
| Разрешение камеры | отложено вместе с добавлением фото (см. `TODO(фото)`) | — |
| Поворот экрана | состояние в ViewModel / rememberSaveable | вручную |

## Заметки для будущих правок

- Инструментальный тест фото (сейчас `@Ignore`) использует `file://` URI; на некоторых образах эмулятора может понадобиться `content://`.
- В CI задача `instrumented` сначала собирает APK и останавливает Gradle и только потом запускает эмулятор: на раннере 2 ядра и около 7 ГБ памяти, поэтому сборку и эмулятор не стоит запускать одновременно.
