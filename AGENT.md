## Проект

**«Домашнее меню» (Home Menu)** — офлайн-приложение для Android: рецепты, меню на неделю, список покупок. Интерфейс только на русском.

- Стек: Kotlin 1.9.24, Jetpack Compose, Material 3, MVVM, Room 2.6, Hilt, Navigation Compose. minSdk 29, target/compile 34.
- `applicationId = com.example.homemenu` — **никогда не менять**.
- Подробности: `DEVELOPMENT_HANDOFF.md`, `README.md`, `DESIGN.md`, `ENVIRONMENT.md` (`TEST_REPORT.md` устарел).

## Как работаем

- У агента нет JDK, Gradle и Android SDK. Собирает и тестирует только GitHub Actions: `build` (сборка, юнит-тесты, Robolectric, lint) и `instrumented` на эмуляторах API 29 и API 34.
- Чтение файлов: временный workflow на ветке `agent-diag` печатает нужные файлы в лог, агент читает лог (см. handoff, раздел A).
- На каждую задачу — ветка от `modernization`, PR, слияние при зелёном CI; затем `modernization` -> `main`.
- Никаких force-push, ключей, паролей и токенов в git. Никакой разрушающей миграции БД.
- Файл `recipes_from_budget_classic_1500kcal.json` — реальный файл пользователя для тестов импорта, **не менять**.
