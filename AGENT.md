# AGENT.md — память агента

Этот файл ведёт ИИ-агент. В начале каждого нового чата агент читает его и продолжает с места, где остановились. После каждого заметного шага агент обновляет разделы «Сделано», «Осталось» и «Журнал».

## Проект

**«Домашнее меню» (Home Menu)** — офлайн-приложение для Android: рецепты, меню на неделю, список покупок. Интерфейс только на русском.

- Стек: Kotlin 1.9.24, Jetpack Compose, Material 3, MVVM, Room, Hilt, Navigation Compose. minSdk 29, target/compile 34.
- Подробности: `README.md` (возможности, сборка), `DESIGN.md` (палитра, шрифты, токены), `TEST_REPORT.md` (тесты), `ENVIRONMENT.md` (среда).

## Как работаем

- В песочнице агента нет JDK, Gradle и Android SDK, интернета тоже нет. Поэтому собирает и тестирует только GitHub Actions (`.github/workflows/android.yml`): задачи `build` и `instrumented` на эмуляторах API 29 и API 34.
- Код агент меняет через GitHub: коммиты в `main`.
- Если коммит меняет только документацию, в сообщение добавляем `[skip ci]`.
